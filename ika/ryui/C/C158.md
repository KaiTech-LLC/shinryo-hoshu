# C158 酸素濃縮装置加算

**(１)** チアノーゼ型先天性心疾患の患者に対して指導管理を行った場合は、酸素濃縮装置加算は別に算定できない。

**(２)** 同一患者に対して酸素ボンベ（携帯用酸素ボンベを除く。）、酸素濃縮装置及び設置型液化酸素装置を併用して在宅酸素療法を行った場合は、合わせて３月に３回に限り算定する。

**(３)** 同一患者に対して携帯用酸素ボンベ及び携帯型液化酸素装置を併用して在宅酸素療法を行った場合は、合わせて３月に３回に限り算定する。
