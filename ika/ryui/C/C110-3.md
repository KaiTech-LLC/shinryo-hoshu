# C110-3 在宅迷走神経電気刺激治療指導管理料

**(１)** 在宅迷走神経電気刺激治療指導管理料は、植込型迷走神経電気刺激装置を植え込んだ後に、在宅において、患者自らがマグネット等を用いて治療を実施する場合に、診察とともに治療効果を踏まえ、装置の状態について確認・調整等を行った上で、当該治療に係る指導管理を行った場合に算定する。

**(２)** プログラムの変更に係る費用は所定点数に含まれる。

**(３)** 計測した指標と指導内容を診療録に添付又は記載すること。
