# K697-3 肝悪性腫瘍ラジオ波焼灼療法（一連として）

**１** ２センチメートル以内のもの

　**イ** 腹腔鏡によるもの　**16,300点**

　**ロ** その他のもの　**15,000点**

**２** ２センチメートルを超えるもの

　**イ** 腹腔鏡によるもの　**23,260点**

　**ロ** その他のもの　**21,960点**

**注** フュージョンイメージングを用いて行った場合は、フュージョンイメージング加算として、200点を所定点数に加算する。
