# C114 在宅難治性皮膚疾患処置指導管理料

**1,000点**

**注１** 皮膚科又は形成外科を担当する医師が、別に厚生労働大臣が定める疾患の患者であって、在宅において皮膚処置を行っている入院中の患者以外のものに対して、当該処置に関する指導管理を行った場合に算定する。

　**２** 区分番号Ｂ００１の７に掲げる難病外来指導管理料又は区分番号Ｂ００１の８に掲げる皮膚科特定疾患指導管理料を算定している患者については、算定しない。
