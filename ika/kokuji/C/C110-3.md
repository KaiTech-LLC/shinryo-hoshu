# C110-3 在宅迷走神経電気刺激治療指導管理料

**810点**

**注１** てんかん治療のため植込型迷走神経電気刺激装置を植え込んだ後に、在宅においててんかん管理を行っている入院中の患者以外の患者に対して、在宅てんかん管理に関する指導管理を行った場合に算定する。

　**２** 植込術を行った日から起算して３月以内の期間に行った場合には、導入期加算として、140点を所定点数に加算する。
