# C108-4 在宅悪性腫瘍患者共同指導管理料

**1,500点**

**注** 別に厚生労働大臣が定める保険医療機関の保険医が、他の保険医療機関において区分番号Ｃ１０８に掲げる在宅麻薬等注射指導管理料の１又は区分番号Ｃ１０８－２に掲げる在宅腫瘍化学療法注射指導管理料を算定する指導管理を受けている患者に対し、当該他の保険医療機関と連携して、同一日に、当該患者に対する麻薬等又は抗悪性腫瘍剤等の注射に関する指導管理を行った場合に算定する。
