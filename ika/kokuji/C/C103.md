# C103 在宅酸素療法指導管理料

**１** チアノーゼ型先天性心疾患の場合　**520点**

**２** その他の場合　**2,400点**

**注１** 在宅酸素療法を行っている入院中の患者以外の患者に対して、在宅酸素療法に関する指導管理を行った場合に算定する。

　**２** 別に厚生労働大臣が定める施設基準に適合しているものとして地方厚生局長等に届け出た保険医療機関において、２を算定する患者について、前回受診月の翌月から今回受診月の前月までの期間、遠隔モニタリングを用いて療養上必要な指導を行った場合は、遠隔モニタリング加算として、150点に当該期間の月数（当該指導を行った月に限り、２月を限度とする。）を乗じて得た点数を、所定点数に加算する。
