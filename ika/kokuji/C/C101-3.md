# C101-3 在宅妊娠糖尿病患者指導管理料

**１** 在宅妊娠糖尿病患者指導管理料１　**150点**

**２** 在宅妊娠糖尿病患者指導管理料２　**150点**

**注１** １については、妊娠中の糖尿病患者又は妊娠糖尿病の患者（別に厚生労働大臣が定める者に限る。）であって入院中の患者以外の患者に対して、周産期における合併症の軽減のために適切な指導管理を行った場合に算定する。

　**２** ２については、１を算定した入院中の患者以外の患者に対して、分娩後も継続して血糖管理のために適切な指導管理を行った場合に、当該分娩後12週の間、１回に限り算定する。
