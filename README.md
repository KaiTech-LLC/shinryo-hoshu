# 診療報酬 shinryo-hoshu

医科診療報酬点数表（告示）と留意事項通知を、**区分ごとの Markdown** にしたリポジトリです。
改定や訂正のたびに 1 つのコミットを積んでいるので、`git log` や `git diff` で「いつ・どこが・どう変わったか」を追えます。

> [!IMPORTANT]
> KaiTech 合同会社が、厚生労働省の公表資料を読みやすく整理した**非公式の写し**です。正本は厚生労働省の原文です。
> 算定の判断にあたっては、必ず原文をご確認ください。

> [!TIP]
> 点数表を区分ごとに検索・閲覧するなら、医療従事者向けの [KaiTech Doctor](https://www.kaitech-doctor.com/fee?utm_source=github&utm_medium=readme) をどうぞ。
> 算定の疑問にチャットで答える機能もあります。

## 中身

| フォルダ | 資料 |
|---|---|
| [`ika/kokuji/`](ika/kokuji/README.md) | 診療報酬の算定方法 別表第一 医科診療報酬点数表（点数と注） |
| [`ika/ryui/`](ika/ryui/README.md) | 診療報酬の算定方法の一部改正に伴う実施上の留意事項について 別添1 医科（算定の取扱い） |

同じ区分は同じファイル名です。初診料なら [`ika/kokuji/A/A000.md`](ika/kokuji/A/A000.md) と [`ika/ryui/A/A000.md`](ika/ryui/A/A000.md) です。
施設基準・DPC なども、今後同じ形で追加していきます。

## ブランチとタグ

| ブランチ | 中身 |
|---|---|
| `main` | いま施行されている版（令和8年度改定と、その後の訂正） |
| `r08` | 令和8年度改定の版。次の改定のあとも、令和8年度版の最終形として残ります |
| `r06` | 令和6年度改定の版 |

公布・訂正の時点ごとにタグ（`r06-20240305`、`r08-20260730`、`r08-20261007`）を付けています。

## 使い方

```bash
git clone https://github.com/KaiTech-LLC/shinryo-hoshu.git
cd shinryo-hoshu
git config core.quotepath false   # 日本語のファイル名をそのまま表示する

# 初診料（告示）の変更履歴
git log --format='%ad %s' --date=short -- ika/kokuji/A/A000.md

# 令和6年度 → 令和8年度で、初診料がどう変わったか（文字単位）
git diff --word-diff=color --word-diff-regex=. r06 r08 -- ika/kokuji/A/A000.md

# 令和8年度改定で変わった区分の一覧
git diff --stat r06 r08 -- ika/kokuji
```

## 表記について

- 本文の文字は原文のままです（全角・半角も原文どおり）。PDF の折り返しによる改行だけをつなぎ直しています。
- 読みやすさのため、項目の深さに応じた字下げ、行頭の番号と点数の太字、区分ごとの見出しを付けています。
- 表は Markdown の表にしています。列が多すぎる表は省略し、原文の PDF の場所を書いています。
- 原文で複数の区分をまとめて書いている見出し（「Ｂ００２ …、Ｂ００３ …」など）は、最初の区分のファイルに載せ、ほかの区分のファイルにはそこへの案内を置いています。

## 査定事例を募集しています

査定や返戻を受けた事例を教えてください。
どの区分が、どんな理由で査定されたかが集まれば、ほかの医療機関が同じ査定を避ける手がかりになります。

- 書き込み先: [Discussions「査定事例」](https://github.com/KaiTech-LLC/shinryo-hoshu/discussions)
- 書いてほしいこと: 区分、審査機関、査定の内容と理由、請求の背景（病名や回数など）

> [!CAUTION]
> **個人情報は書かないでください。**
> 患者さんの氏名・生年月日・保険者番号、医療機関名、レセプトの画像など、患者さんや医療機関を特定できる情報は書き込まないでください。
> 年齢は「70代」、時期は「2026年9月診療分」のように、ぼかして書いてください。
> 個人情報を含む書き込みは、気づいた時点で KaiTech が削除します。

査定の判断は審査機関や地域によって違うことがあり、ほかの医療機関に同じく当てはまるとは限りません。
